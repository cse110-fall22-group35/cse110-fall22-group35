# CSE 110 – Software Engineering Group Project

This repository contains our group’s software engineering project for **CSE 110: Software Engineering** at **UC San Diego** (Fall 2022).  
Our team followed Agile development practices to design, implement, and test a full-stack application demonstrating collaboration, version control, and real-world software workflows.

---

## 🧩 Overview
The project aimed to simulate an end-to-end product cycle — from brainstorming and requirements gathering to implementation and testing.  
Key goals included:
- Practicing **Agile methodology** (scrum meetings, sprint planning, retrospectives)
- Collaborating through **GitHub issues, branches, and pull requests**
- Writing clean, maintainable, and testable code
- Delivering a working, deployable product with proper documentation

---

## ⚙️ Tech Stack
| Layer | Technologies |
|-------|---------------|
| **Frontend** | HTML · CSS · JavaScript · Bootstrap |
| **Backend** | Node.js · Express |
| **Database** | Firebase / Firestore |
| **Development Tools** | Git · GitHub · VS Code · npm |
| **Testing** | Jest · Cypress · Manual QA |
| **Deployment** | GitHub Pages / Firebase Hosting |

---

## 🧠 Features
- User authentication and data storage  
- Responsive UI built with HTML/CSS/JS  
- Modular architecture with separation of concerns  
- Automated testing with CI/CD integration  
- Comprehensive documentation and user guide

---

## 👥 Team & Collaboration
- Developed in a **team of 6–8 students** under Agile sprints  
- Used **Git branching strategy** (feature / dev / main)  
- Conducted **code reviews** and **pair programming** sessions  
- Managed tasks using **GitHub Projects + Issues**

---

## 🧪 Testing & Quality Assurance
- Unit tests with **Jest**
- End-to-end tests with **Cypress**
- Linting and code-style enforcement
- Peer review and continuous integration
